# Assignment 2-3 Part B – IDE Features Reflection

## Introduction
Writing, running, and testing code inside Visual Studio Code provided a structured and efficient workspace for completing this assignment. Rather than working in a basic text editor and switching tools, the IDE brings the text editor, error checking, and terminal into a single window. Learning to navigate these built-in features early helps eliminate interface friction and allows beginning programmers to focus on code logic. During the development of `name_age.py`, three features proved especially valuable: syntax highlighting, the integrated terminal, and IntelliSense code completion.

## Feature 1 – Syntax Highlighting
Syntax highlighting automatically color-codes different components of Python syntax, such as functions, variable identifiers, and string literals. While writing the script, syntax highlighting made it immediately obvious that functions like `input()` and `int()` were recognized, while user prompts appeared in distinct string colors. This visual separation prevented syntax errors, such as unmatched quotation marks or misplaced parentheses, before running the script.

## Feature 2 – Integrated Terminal
The integrated terminal provides an embedded command line directly below the code editor window. Instead of leaving VS Code to run external commands, the integrated terminal allowed running `name_age.py` and interacting with the prompts in the exact same workspace. This immediate execution loop made testing multiple inputs and checking the birth year output quick and seamless.

## Feature 3 – IntelliSense and Autocomplete
IntelliSense offers live code suggestions, function definitions, and attribute completion as code is typed. When working with the `datetime` module, IntelliSense suggested available functions and verified the syntax for `datetime.date.today().year`. This prevented typos, reinforced proper Python syntax, and eliminated the need to stop and search outside documentation.

## Conclusion
Using an IDE for this assignment demonstrated how modern developer tools support beginners by catching small mistakes and speeding up testing cycles. Features like syntax highlighting, integrated terminal execution, and IntelliSense allow developers to focus on problem-solving rather than troubleshooting setup issues. These foundational tools build confidence and provide a strong workflow for future programming coursework.
